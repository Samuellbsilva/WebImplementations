# TrabalhoWeb

Repositório com os arquivos desenvolvidos durante a disciplina de Desenvolvimento Web. Aqui estão organizados os exercícios de aula e um projeto de site completo.

## Estrutura do projeto


```
TrabalhoWeb/
├── html/           → Snippets e exercícios de HTML
├── css/            → Snippets e exercícios de CSS
└── TrabalhoSite/   → Site completo do Dr. Moacir da Silva
```

## 📁 html/

Contém 14 pastas (Html01 a Html14), cada uma com snippets de código HTML extraídos de vídeos do YouTube durante as aulas. Os exercícios vão evoluindo ao longo das pastas, cobrindo desde a estrutura básica do HTML até tópicos como:

- Tags de texto, links e imagens
- Listas e tabelas
- Formulários
- Áudio e vídeo
- HTML semântico
- Navegação entre páginas

## 📁 css/

Contém duas subpastas com snippets de CSS também extraídos de vídeos do YouTube:

- **aulas/** — Exercícios de estilização com CSS puro, trabalhando propriedades como cores, fontes, layout e responsividade.
- **aula28site/** — Um mini-site construído durante uma aula específica, aplicando os conceitos de CSS aprendidos.

## 📁 TrabalhoSite/

Site completo desenvolvido como trabalho da disciplina. É uma landing page para o **Dr. Moacir da Silva**, um psicólogo, psicanalista e sexólogo de Uberlândia-MG.

### O que tem no site:

- **Header fixo** com navegação e logo
- **Hero section** com vídeo de fundo, frase de impacto e botão de agendamento
- **Seção "Sobre"** com foto, bio e credencial (CRP)
- **Seção "Abordagem"** com os 4 serviços oferecidos (terapia individual, de casais, sexologia clínica e atendimento online)
- **Seção "Agendar"** com call-to-action para marcar consulta
- **Footer** com logo e CRP

### Tecnologias usadas:

- HTML5 semântico
- CSS3 puro (variáveis CSS, flexbox, animações, media queries)
- Google Fonts (Cinzel, Montserrat, Pinyon Script)
- Design responsivo (adaptado para desktop, tablet e mobile)
